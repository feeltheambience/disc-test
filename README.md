# DISC-тест

Telegram Mini App для DISC-тестирования: отвечаешь на вопросы, получаешь профиль (D/I/S/C) с расшифровкой.
Живёт на GitHub Pages: https://feeltheambience.github.io/disc-test/

Статика: `index.html`, `app.js`, `style.css`, вопросы — в `questions.js`. Подсчёт и расшифровка целиком на клиенте, бэкенда нет.

Запуск локально — открыть `index.html`. Чтобы поменять вопросы, правится `questions.js`.
